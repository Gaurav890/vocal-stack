# Browser demos

Try `vocal-stack` in a browser without configuring a model, TTS provider, or API key.

## Start with the v2 reliability demo

[Open the interactive v2 demo in StackBlitz](https://stackblitz.com/github/Gaurav890/vocal-stack/tree/main/stackblitz-demos/03-full-pipeline)

The demo shows the complete provider-neutral path:

```text
model deltas → speech-safe segments → simulated TTS → playback acknowledgement
```

Run a complete turn, then run it again and interrupt mid-stream. The result makes the package's
core distinction visible: text generated by a model is not necessarily text the listener heard.

## Available demos

| Demo | API | What it demonstrates |
| --- | --- | --- |
| [Interactive reliability pipeline](./03-full-pipeline) | v2 | Streaming normalization, segmentation, barge-in, heard-text accounting, and metrics |
| [Text sanitizer](./01-basic-sanitizer) | deprecated v1 compatibility | Configurable complete-string sanitization |
| [Flow controller](./02-flow-control) | deprecated v1 compatibility | Legacy stall detection and filler callbacks |

New integrations should use the v2 `/text`, `/turn`, `/telemetry`, and `/testing` entry points. The
legacy demos remain available to help existing v1 applications migrate.

## Run locally

```sh
cd stackblitz-demos/03-full-pipeline
npm install
npm run dev
```

The repository validates every demo against a freshly packed local artifact. The v2 demo's complete
and interrupted paths also run in the Chromium, Firefox, and WebKit CI matrix.

For provider integrations, see the [compile-checked recipes](../recipes). For the public API, see
the [API reference](../docs/API.md).
