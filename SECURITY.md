# Security policy

## Supported versions

Security fixes are provided for the latest v2 release. During the v2 release-candidate phase,
reports are evaluated against the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting for this repository. Include affected versions, impact, reproduction steps, and any known
mitigation.

The project does not collect prompts, transcripts, tool arguments, or speech content through its
default telemetry schema. Applications remain responsible for provider credentials, audio data,
transport security, and telemetry retention.
